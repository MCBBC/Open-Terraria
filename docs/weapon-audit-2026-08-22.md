# 丛林远景背景接续露馅(2026-08-25,用户报+实机截图+存档取证)

**根因**:BiomeBackground drawLayer 的平铺步进 `wScaled = im.width × scale`——但
动画层(opt.anim)实际只绘制**半宽帧**(`sw = im.width >> 1`,2×2 帧表取帧 0,
GetBackgroundRect Frame(2,2,col,row) 同式)→ **stride = 绘制宽 ×2** → 每两块
背景之间空出 50% 的天空(Background_59 实测 1024 宽=2 帧 512;步进 2560 vs 绘制
1280)。丛林层平涂绿填充的断口最刺眼(用户实机截图竖直硬边);森林树层同病但
"树间隙"观感自然故长期未暴露。

**修**:一行 `wScaled = sw × scale`(帧宽×scale;静态层 sw=整宽不变)。影响全部
opt.anim 背景层(森林/丛林/腐化/猩红/雪原/神圣/蘑菇/沙漠树层)——缝全部消失,
填充连续。云层(112/113)整图直取无此病。

**验证**:用户实机确认修复(无需探针)。另注:探针跳 worldgen 直读档
(__swFlow.loadJson 标题页直调)比建图+读档快 3-5 分钟。
